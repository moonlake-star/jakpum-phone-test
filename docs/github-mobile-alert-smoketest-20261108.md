# GitHub Mobile 알림 전달 시험 — 2026-11-08

이 파일은 병합/Pages 배포에 따른 GitHub Mobile 알림이 자동 발생하는지 검증하기 위한 **문서 전용 무해한 테스트 변경**입니다.

- 테스트 경로: PR 병합 → `github-actions[bot]`의 병합 알림 → GitHub Pages 배포 이벤트 → `github-actions[bot]`의 배포 알림
- 기대 알림은 GitHub Issue #569의 멘션 댓글입니다.
- 이 변경은 선생님/학생 화면, 소스 코드, 데이터, 음원, 설정, Secrets, 가격과 결제에 영향을 주지 않습니다.
- GitHub 서버 기준 PR 병합 및 댓글 생성 시각을 비교합니다. **휴대폰 푸시 수신 시각은 실제 휴대폰에서만 측정 가능**합니다.
- 이 테스트는 병합과 배포 자체는 실제로 발생하므로, 메시지에는 그 단계를 사실대로 기록합니다. 사용자 기능 변경은 없습니다.
