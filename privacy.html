작품 보컬노트 개인정보 처리방침

시행일: 2026년 10월 24일 · 운영: 뮤직스튜디오 작품

「작품 보컬노트」는 뮤직스튜디오 작품이 자체 수강생의 보컬 레슨 기록을 관리하기 위해 쓰는 내부 도구입니다. 일반 사용자에게 공개된 서비스가 아니며, 동의한 수강생의 자료만 처리합니다.

1. 처리하는 정보

항목목적
레슨 녹음(음성)레슨 내용 전사, 노래 구간 클립, 피드백 작성
카카오톡 대화·통화 전사(수강생이 동의한 것)수강생별 레슨 메모·선곡·과제 정리
레슨 일정(구글 캘린더)레슨 회차·결제 주기 확인
이름·연락용 별칭자료를 해당 수강생에게 연결

2. 구글 사용자 데이터의 사용

이 도구는 운영자 본인의 구글 계정에 한해 Google Drive(레슨 자료 폴더 읽기·정리·저장)와 Google Calendar(레슨 일정 읽기) 권한을 사용합니다. 구글에서 받은 데이터는 위 목적에만 쓰며, 판매하거나 광고에 쓰지 않고, 아래 처리 위탁 외에는 제3자에게 넘기지 않습니다. 구글 사용자 데이터를 AI 모델 학습에 쓰지 않습니다. Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

3. 처리 위탁 및 국외 이전

받는 곳내용위치
Google LLC (Drive·Calendar)자료 보관·일정미국 등
AssemblyAI, Inc.레슨 녹음의 음성→텍스트 변환(화자 구분)미국
GitHub, Inc. (Actions)예약된 시간에 정리 작업 실행(자료를 보관하지 않음)미국

녹음은 변환에 필요한 동안만 전송되며, 위탁처의 모델 학습 사용은 거부 설정을 원칙으로 합니다.

4. 보관 기간과 삭제

수강 기간 동안 보관하고, 수강 종료 후 수강생이 요청하면 지체 없이 삭제합니다. 요청이 없으면 종료 후 1년이 지나면 삭제합니다.

5. 수강생의 권리

수강생은 언제든 자신의 자료 열람·정정·삭제와 처리 중단을 요청할 수 있습니다. 요청은 담당 선생님께 카카오톡 또는 레슨 중 말씀해 주시면 됩니다.

6. 문의
