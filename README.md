# P0-A 폰 실험 페이지

**목적:** 안드로이드 앱을 만들지 않고도 되는지 두 가지를 Galaxy S25+에서 확인한다.
1. 삼성 음성 녹음 앱 → 공유 → 이 웹앱(설치형 PWA)으로 녹음 파일이 넘어오는가 (파일 형식·크기·길이 기록)
2. 웹앱에서 클립 파일 + 문구를 안드로이드 공유 메뉴로 카카오톡에 보낼 수 있는가 (문구가 함께 가는지)

## 검증 상태 (2026-10-23)
| 항목 | 상태 |
|---|---|
| 서비스 워커 등록·제어, 공유 수신(POST) 저장, 길이 표시, 지우기, 결과 JSON | 데스크톱 헤드리스 크롬에서 **모의 시험 통과** (콘솔 오류 0) |
| 실제 안드로이드 공유 목록 표시·카톡 전송 | **미검증** — 폰에서 확인하는 것이 이 실험의 목적 |

## 배포
- HTTPS가 필요하다. **GitHub Pages**(무료)에 이 폴더만 올린다.
- 무료 GitHub 계정은 **공개 저장소에서만 Pages**를 쓸 수 있으므로, 이 실험 페이지는 별도 공개 저장소(예: `jakpum-phone-test`)에 둔다. 이 폴더에는 개인정보가 없다(합성 사인파 샘플만 포함). 본 코드는 비공개 저장소에 둔다.

## 개인정보
- 공유받은 파일은 그 폰의 브라우저 저장소(Cache Storage)에만 저장되고 어디에도 업로드되지 않는다.
- '받은 파일 지우기'로 삭제. 앱을 삭제해도 지워진다.
