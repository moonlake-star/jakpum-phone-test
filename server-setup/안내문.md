# 새 노트북 서버 만들기 — 순서 안내 (2026-11-18)

목표: 새 노트북(Windows 11)에 **파일 하나(setup_server.bat)** 만 실행하면 설정·설치가 자동으로 끝난다.
사람이 해야 하는 일은 아래 ①~⑦뿐이다(보안상 대신 할 수 없는 것들).

## 준비(옛 노트북, 5분)
① 옛 노트북에서 https://moonlake-star.github.io/jakpum-phone-test/server-setup/ 를 열어 **export_keys.bat, export_keys.ps1** 두 개를 같은 폴더에 받는다.
② **export_keys.bat** 더블클릭 → 열린 폴더 `jakpum_keys_pack`(키·구글 열쇠·GitHub 로그인이 들어 있음)을 **USB에 복사**한다. 이 폴더는 비밀이니 USB로만 옮기고 인터넷에 올리지 않는다.
   - 창에 "못 찾음"이 뜨는 항목이 있으면 그 줄 사진을 Claude에게 보낸다.

## 새 노트북
③ 전원을 켜고 Windows 첫 설정(언어·와이파이·계정)을 끝낸다. 인터넷에 연결한다.
④ 새 노트북에서 위 페이지를 열어 **setup_server.bat, setup_server.ps1** 두 개를 같은 폴더(바탕화면 등)에 받는다.
   - 받을 때 "위험할 수 있음" 경고가 뜨면 [유지]를 누른다(우리가 만든 파일이다).
⑤ **setup_server.bat 더블클릭** → 'Windows가 이 앱이 변경하도록 허용할까요?' 에서 **[예]** → 검은 창에서 질문 2개에만 답한다:
   1. Windows 암호(자동 로그인용, 없으면 Enter)
   2. USB를 꽂고 Enter(열쇠 폴더를 자동으로 찾는다)
⑥ 그다음은 **자리를 비워도 된다.** 설치 → Windows 업데이트 → 저절로 재시작 → 이어서 설치 → 시험까지 자동(대략 40~90분, 인터넷 속도에 따라).
⑦ 끝나면 바탕화면 검은 창에 결과가 뜬다. **그 창 사진을 Claude에게 보낸다.** 실패 항목은 Claude가 원격으로 고친다.

## 마지막에 사람이 직접 해야 하는 것(최후의 수단, 순서대로)
1. **Google 드라이브 앱 로그인**: 자동으로 열린 창에서 작품 앱 구글 계정으로 로그인 → 설정에서 '내 드라이브 미러링/스트리밍'은 기본값 그대로.
2. **Claude 앱 로그인**: 자동으로 열린 Claude 창에서 로그인 → 설정에서 이 컴퓨터 연결(데스크톱 앱 연결)을 켠다. 그래야 Claude가 이 노트북을 원격으로 점검한다.
3. **Chrome에서 'Claude in Chrome' 확장 프로그램 설치**: Chrome 웹 스토어에서 'Claude' 확장을 추가하고 같은 계정으로 로그인(회사 정책상 자동 설치가 안 되는 부분).
4. **GitHub 로그인 창이 뜨면**(열쇠 폴더에 GitHub 로그인이 없을 때만): 창에 나온 8자리 코드를 브라우저에서 입력하고 승인.
5. **옛 노트북 일꾼 끄기**: 새 노트북이 정상(Claude가 확인해서 알려 줌)이면 옛 노트북의 일꾼 창을 닫고 시작프로그램에서 뺀다 — 둘이 동시에 돌면 같은 일을 두 번 한다.
6. USB의 `jakpum_keys_pack` 폴더를 **삭제**한다.

## 자동으로 해 주는 것
- 전원: 절대 안 잠듦·덮개를 닫아도 계속·최대 절전/빠른 시작 끔·USB/PCIe/무선랜 절전 끔·화면만 꺼짐
- 정전·재부팅 후 자동 로그인 → 일꾼 자동 실행, 5분마다 꺼졌는지 확인해 되살림
- Windows 업데이트·드라이버, 위젯·광고·불필요 효과 끔, 시간 동기화, 업데이트가 일하는 중 재시작하지 않게(일요일 04:30 점검 재시작만)
- 설치: Git, GitHub CLI, Python 3.11, FFmpeg, yt-dlp, Chrome, Google 드라이브, Claude 데스크톱, Claude Code, GPU용 torch, demucs 등
- 코드 받기 → 시험 실행 → 결과 `C:\jakpum\설정결과.txt` (기록: `C:\jakpum\setup.log`)

## 알아둘 점(솔직하게)
- 이 스크립트는 만든 환경에서 Windows로 실행해 본 적이 없다. 어딘가 막히면 로그(setup.log)로 Claude가 고친다. 같은 파일을 다시 실행해도 안전하다(된 것은 건너뜀).
- 자동 로그인 암호는 Windows 레지스트리(Sysinternals Autologon: 암호화 저장)에 들어간다. 노트북 분실 위험이 있으면 BitLocker 켜기를 권한다.
- 덮개를 닫고 쓰면 발열이 커진다. 열어 둔 채 거치대에 세우거나 팬이 잘 도는 곳에 두는 것을 권한다.
